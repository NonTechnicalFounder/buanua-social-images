# Bua Nua social images

Public image host for scheduled Bua Nua social posts.

Images are referenced by Buffer at publish time via deterministic raw URLs:

```
https://raw.githubusercontent.com/NonTechnicalFounder/buanua-social-images/main/<week>/<file>.png
```

Folders are named by the Monday of the posting week.
